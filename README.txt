منصة بصائر — نسخة روابط المحاضرات (Static / GitHub Pages)

هذه النسخة لا تحتوي على نظام بث داخلي أو خادم خلفي.
الموجود:
- index.html: الموقع الرئيسي وروابط المحاضرات.
- الصور الأصلية المستخدمة في التصميم.

تم حذف:
- خادم Node.js وملفات LiveKit.
- قاعدة بيانات PostgreSQL وملفات SQL.
- صفحة تسجيل الدخول ولوحات الطلاب والمحاضرين.
- إعدادات Render وملفات إعداد الخادم.

إضافة روابط Google Meet أو Zoom:
1. افتحي index.html باستخدام محرر نصوص.
2. ابحثي عن السطر الذي يبدأ بـ const CONFIG=
3. ضعي رابط الاجتماع بين علامتي الاقتباس أمام الحلقة المطلوبة:
   live:{quran:'رابط-الاجتماع',tajweed:'',sharia:''}
4. يمكن وضع روابط Google Maps في قسم maps بالطريقة نفسها:
   maps:{quran:'رابط-الخريطة',tajweed:'',sharia:''}
5. احفظي الملف ثم ارفعيه إلى GitHub Pages.

مفاتيح الحلقات:
- quran = تحفيظ القرآن
- tajweed = التجويد والتلاوة
- sharia = العلوم الشرعية

طريقة الاستخدام:
- المحاضِرة تنشئ الاجتماع بنفسها من Google Meet أو Zoom.
- تنسخ رابط الاجتماع وتضعه في إعدادات CONFIG داخل index.html.
- الطالب يضغط «فتح المحاضرة» فينتقل مباشرة إلى الاجتماع.
- زر «موقع الحلقة» يفتح Google Maps إذا تمت إضافة الرابط؛ وإذا لم يُضف، يظهر تنبيه للتواصل مع الإدارة.

لا توجد حسابات طلاب أو محاضرين داخل الموقع، ولا يلزم Node.js أو PostgreSQL أو Render أو مفاتيح API.
ملاحظة: يجب أن تكون روابط الاجتماعات صالحة ومسموحًا للطلاب بالدخول إليها حسب إعدادات Meet أو Zoom.
