# منصة بصائر — نسخة أزرار المحاضرات الثلاثة

## أزرار المحاضرات الجاهزة
تحتوي الصفحة الرئيسية على ثلاثة أزرار جاهزة في قسم «روابط المحاضرات»:
1. تحفيظ القرآن — المفتاح `quran`
2. التجويد والتلاوة — المفتاح `tajweed`
3. العلوم الشرعية — المفتاح `sharia`

## إضافة روابط Zoom أو Google Meet لاحقًا
1. افتحي ملف `index.html` باستخدام محرر نصوص.
2. ابحثي عن `const CONFIG={`.
3. ستجدين هذا الجزء:

```js
live:{quran:'',tajweed:'',sharia:''},
```

4. ضعي رابط كل اجتماع بين علامتي الاقتباس الخاصتين به، مثل المثال التالي (استبدلي الرابط برابط اجتماعك الحقيقي):

```js
live:{
  quran:'https://zoom.us/j/PUT-MEETING-LINK-HERE',
  tajweed:'https://zoom.us/j/PUT-MEETING-LINK-HERE',
  sharia:'https://zoom.us/j/PUT-MEETING-LINK-HERE'
},
```

يمكن استخدام روابط Google Meet أيضًا. لا تضعي أي مسافات أو نصوص إضافية داخل الرابط.

5. احفظي الملف ثم ارفعي النسخة المحدّثة إلى مستودع GitHub Pages.
6. عند الضغط على زر أي محاضرة، يفتح رابطها مباشرة في نافذة جديدة. إذا كان الرابط فارغًا، تظهر رسالة تفيد بأن الرابط لم يُضف بعد بدلًا من فتح رابط غير صحيح.

## ملاحظات
- الأزرار الثلاثة موجودة بالفعل في قسم «روابط المحاضرات» ولا تحتاجين إلى إنشاء أزرار جديدة.
- لا يحتاج الطالب إلى حساب على الموقع أو إلى معرفة إيميل المحاضر.
- دخول Zoom يظل خاضعًا لإعدادات الاجتماع التي يحددها المحاضر (مثل كلمة المرور أو السماح للضيوف).
- استمارة التسجيل الحالية وباقي تصميم الموقع محفوظان.
